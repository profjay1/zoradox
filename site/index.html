// 05 — Work

How we’d build it.

Concept projects showing how we’d approach a typical build for a startup, a medium-sized business and an enterprise.

Concept project Startup

Appointment booking platform

For a wellness startup

Goal
Let clients book sessions online at any time, and reduce missed appointments.
Approach
A fast, mobile-first booking flow, automatic email reminders, and an admin calendar where staff manage availability and appointments.
Stack
  • Angular
  • TypeScript
  • Spring Boot
  • PostgreSQL

Concept project Medium business

Operations dashboard

For a regional logistics company

Goal
Replace scattered spreadsheets with one shared, up-to-date view of deliveries and operations.
Approach
A central dashboard with delivery tracking and exportable reports, connected to existing systems through REST APIs.
Stack
  • Angular
  • TypeScript
  • Spring Boot
  • REST APIs
  • PostgreSQL
  • Docker

Concept project Enterprise

Employee self‑service portal

For a large organization

Goal
Give employees one place to request leave, and give managers a clear approval flow.
Approach
Leave requests with multi-step approvals, role-based access for employees, managers and HR, and audit logs that record every change. Documented and handed over to the in-house team.
Stack
  • Java
  • Spring Boot
  • Angular
  • PostgreSQL
  • Docker
  • Nginx
